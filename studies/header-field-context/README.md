# A header label must not become private source text

The baseline at `c8170d20db4e11cd891e013199f4131ed6cf7807` masks a decoded
Authorization value by prepending `Authorization: `, running the complete
masker and slicing off the original prefix length. The masker can legitimately
change that prefix's length: a configured name backend sees it as source text.
The result loses its scheme or part of its surrogate while the vault acquires
an entity that never appeared in the original value.

The controlled reproduction uses the supported `KnownEntitiesBackend` with
`orgs=["Authorization:"]`. This deliberately targets the invented label; it
is not a claim about a common organization name or a naturally observed attack.
The real JSON key `Authorization` does not match that configured phrase, so
the existing sensitive-key guard does not reject this request.

| Decoded value | Before masking | Before restoration | Corrected masking | Corrected restoration |
| --- | --- | --- | --- | --- |
| `Bearer abc` | `⟨SECRET_1⟩` | `abc` | `Bearer ⟨SECRET_1⟩` | `Bearer abc` |
| Native generated Basic value | Scheme lost | Credential without scheme | Scheme preserved | Original value |

The credential stays masked in this reproduction; the defect is corrupted
protocol data and invented vault provenance. The six direct controls fail
before and pass after. All **24 actual SDK paths** fail before and pass after:
Chat Completions, Responses and Anthropic Messages, synchronous/asynchronous,
buffered/one-character streams, and text/tool replies. The SDKs use their own
serialization over mock HTTP transports; no provider, model or authentication
calls occur. Caller input and unrelated JSON spelling remain intact; Anthropic
receives typed tool data, so its check compares that data rather than raw JSON
spelling.

[Before](before.json) and [after](after.json) retain complete outgoing request
bodies, restored replies, vault mappings, module hashes and package versions.
Basic input is generated by the installed SDK's native HTTP library from
invented credentials. This correction does not change Basic/Bearer credential
grammar, authenticate credentials or claim coverage for other auth schemes.

The key now travels through the existing field-context API. `SecretDetector`
recognizes its credential span relative to the **original value**, while name
backends and restoration see only that original text. No synthetic text is
allocated or trimmed. The same behavior is available directly with
`masker.mask(value, field_name="Authorization")`.

Real label text in another value is still masked. A genuinely sensitive JSON
key still rejects before transport. Bare `Bearer abc` without a header key,
unsupported token boundaries, ordinary password contexts, request reservations
and exact/streamed restoration retain their policies. The full source suite
passes 1,615 checks, Ruff and mypy on 36 modules.
